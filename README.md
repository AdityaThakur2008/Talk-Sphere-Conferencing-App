# 🎥 Talk Sphere Conferencing App

A **full-stack, real-time video conferencing application** built with WebRTC, Socket.IO, Node.js, and React. It supports 1:1 and group video calls, screen sharing, real-time chat, authentication, and call history.

---
🌐 Live Demo
🔗 Live Demo: https://talk-sphere-p8s5.onrender.com/

## **Features**

- 🔹 **P2P & Group Video Calls** – 1:1 and multi-user conferencing  
- 🔹 **Screen Sharing** – Share your screen during calls  
- 🔹 **Real-Time Chat** – Instant messaging using Socket.IO  
- 🔹 **Authentication** – Secure login with JWT and protected routes  
- 🔹 **History Section** – Access previous calls and chat logs  
- 🔹 **Interactive UI** – Modern, AI-assisted design  

---

## **Tech Stack**

- **Frontend:** React, CSS/Material UI, AI-assisted UI  
- **Backend:** Node.js, Express.js, Socket.IO, JWT  
- **Database:** MongoDB (for chat/call history and User Data)  
- **Real-Time Communication:** WebRTC
